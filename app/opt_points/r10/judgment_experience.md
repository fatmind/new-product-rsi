# 研判经验（① 选品研判 prompt 的知识来源）

> 场景：3C 消费电子 - 大单品配件，出海电商。
> 自迭代规则：每轮可改 / 增 / 删条目，日志记编号；条目只写「怎么判断」，不写输出格式——格式约束写死在代码里，改经验不许动格式。

| 编号 | 经验 |
|---|---|
| E1 | 三层对照定新星：站外需求涨 + 站外销售涨 + 站内有需求没供给 = 需求真、被验证、我们缺货，就是机会；查站外销售这层时，搜索热度涨但竞对销量不涨反跌的簇，热度还没变成购买，别提前进场 |
| E2 | 看规模别只看涨：搜索热度和竞对销量的绝对量级要和同轮其他候选比，明显小一档的簇撑不起破零，价位带贴住竞对价格带也救不了，别推；增速快、品类新、竞争少、先发优势都不构成破零保障，破零看的是绝对量级；客单价偏高的簇，即使需求在涨、价位带贴得住竞对价格带，我们平台的买家盘也撑不起稳稳破零，别推 |
| E3 | 真缺口才值得推：站内只要已经有订单（哪怕总量只有几十单）就是存量生意——已经有商家在卖、有供给，新发品是去抢老商家的单，别当缺口推；别拿「订单不多、一周偶尔一两单」当理由把存量簇说成没人卖。真缺口只认一种：站内零订单、需求还在涨的簇 |
| E4 | 破零潜力按人群拆开看：运动健身、学生、白领这类带着明确目的来的人群，流量和销量才有含金量；闲逛、捡漏人群几乎只看不买。按人群拆开算有效盘，簇总流量大但人群薄的凑不够破零线，别被总数唬住。跨轮再看买单人群：稳定不破零的簇几乎都只有一个群在买，单一人群的簇就算偶尔破一次也不稳、别按稳簇复推；买单人群不止一个的簇才扛得住波动 |
| E5 | 多市场共振更可靠，但只是加分不是门槛：只有一国热、但那个市场热度够大、目的性人群对得上，照样能稳稳破零，别因为「只有一国热」就放弃 |
| E6 | 竞对价格带是接受度证据：竞对已经在卖的价位就是消费者验证过的价位；我们价位带明显高于竞对价格带的簇，需求再热也难破零，别推 |
| E7 | 复推和止损数着数执行：破零的簇主力市场没塌（竞对销量稳在高位或还在涨、我们平台还是零供给）就全数复推，这是每轮的保底分子。没破零的簇只数实付已压进竞对价格带的轮次，累计两轮没破零的，第三轮起见到就放弃，不看理由、不翻案——连着两轮没破、哪怕只差一单也是稳定够不着线；跨轮聚合判「稳定不破零」的簇立即止损。实付没进带的失败是引导问题、不是簇的问题，修价重推一次、实付压得比上轮更深，这种轮次不计入止损计数。真正的例外只有两种、各只给一次：首推就卖到 4 单、差 1 单、且买单人群不止一个的，再推一次、实付压深；跨轮销量贴着破零线起伏的噪声簇（几轮里既有接近线的也有明显低点），给一次压深价重测。靠压深实付才破零的贴线簇和噪声簇，破零后照常复推，但实付继续按重测深度对待、别放回竞对中位附近——它只在深价下破过零，价格一放回去就退回贴线状态 |
| E8 | 每轮名单分两步排。第一步先把上一轮全部下发簇摆出来、逐个定去向：稳定破零还健在的（主力市场没塌：竞对销量稳在高位或还在涨、我们平台还是零供给）免检复推，每一簇都必须进名单、一个不许漏——已经反复破零的事实比市场热度的推断硬，不许拿「单一市场」「热度没涨」这类首轮判据回去翻案；符合救援条件的（首推就卖到 4 单、差 1 单、且买单人群不止一个）和该压深重测的噪声簇单独数一遍、也要排进去；深价才破零的簇照常复推、实付按 E7 的重测深度对待；跨轮聚合判「稳定不破零」的立即排除，不看理由、不翻案。第二步再从本轮候选里排新过全部检验的新簇；以上加起来不足 3 个，再从候选里挑否决理由最软的补——只差一条检验、且那条能靠修价或多推一轮翻案的才算数，有硬伤的（价位带够不着、明显小一档、存量生意、单一薄人群）一个都不凑数；已止损的死簇永远不占名额。名单定稿前必须把第一步列出的每个复推簇和最终名单逐个核对一遍，缺哪个补哪个，这道核对不许跳过。名单该几个就几个，别为了省事或好看砍到只剩一两个 |
