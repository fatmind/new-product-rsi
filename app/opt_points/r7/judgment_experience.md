# 研判经验（① 选品研判 prompt 的知识来源）

> 场景：3C 消费电子 - 大单品配件，出海电商。
> 自迭代规则：每轮可改 / 增 / 删条目，日志记编号；条目只写「怎么判断」，不写输出格式——格式约束写死在代码里，改经验不许动格式。

| 编号 | 经验 |
|---|---|
| E1 | 三层对照定新星：站外需求涨 + 站外销售涨 + 站内有需求没供给 = 需求真、被验证、我们缺货，就是机会 |
| E2 | 防假热闹：站外搜索热度在涨但站外销量不涨反跌的簇，热度还没变成购买，别提前进场 |
| E3 | 看规模别只看涨：搜索热度和竞对销量的绝对量级要和同轮其他候选比，明显小一档的簇撑不起破零，价位带贴住竞对价格带也救不了，别推；增速快、品类新、竞争少、先发优势都不构成破零保障，破零看的是绝对量级；客单价偏高的簇，即使需求在涨、价位带贴得住竞对价格带，我们平台的买家盘也撑不起稳稳破零，别推 |
| E4 | 真缺口才值得推：站内一直有稳定订单的簇是存量生意，新发品抢的是老商家的单，流量再大、竞对卖得再多也别当缺口推；站内零订单、需求还在涨的簇才是真缺口 |
| E5 | 破零潜力按人群拆开看流量：运动健身、学生、白领这类带着明确需求来的人群，流量才有含金量；闲逛、捡漏人群几乎只看不买。要按人群拆开算有效盘——一个簇的有效盘只集中在单一人群、那群人的量撑不起破零线的话，簇总流量再大也别推；人群薄的簇凑不够破零线，别被簇的总流量唬住 |
| E6 | 多市场共振更可靠，但只是加分不是门槛：只有一国热、但那个市场热度够大、目的性人群对得上，照样能稳稳破零，别因为「只有一国热」就放弃 |
| E7 | 竞对价格带是接受度证据：竞对已经在卖的价位就是消费者验证过的价位；我们价位带明显高于竞对价格带的簇，需求再热也难破零，别推 |
| E8 | 复推、止损、每轮名单都数着数执行：破零的簇主力市场没塌（竞对销量稳在高位或还在涨、我们平台还是零供给）就全数复推，这是每轮的保底分子；没破零的簇一个簇最多推两轮，第二轮只给两种情况——首推败在价位带没贴住竞对价格带的，修价重推一次，实付要压得比上一轮更深，不是原价再挂一轮；首推就卖到 4 单、差 1 单破零且买单人群不止一个的，也再推一次，同样把实付压深；其余首推失败直接放弃，推满两轮还没破零的、或失败原因是量级小、人群薄、存量生意的，第三轮起见到就放弃，不再给理由。判断是不是毛刺看同簇多轮销量，几轮的最大值都够不到破零线就是稳定破不了。每轮名单先排满再出手：稳定破零还健在的簇全数复推打底，加上新过全部检验的新簇；加起来不足 3 个，就从本轮候选里挑否决理由最软的补——只差一条检验、且那条能靠修价或多推一轮翻案的才算数，有硬伤的（价位带够不着、明显小一档、存量生意、单一薄人群）一个都不凑数 |
