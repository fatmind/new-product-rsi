# 研判经验（① 选品研判 prompt 的知识来源）

> 场景：3C 消费电子 - 大单品配件，出海电商。
> 自迭代规则：每轮可改 / 增 / 删条目，日志记编号；条目只写「怎么判断」，不写输出格式——格式约束写死在代码里，改经验不许动格式。

| 编号 | 经验 |
|---|---|
| E1 | 三层对照定新星：站外需求涨 + 站外销售涨 + 站内有需求没供给 = 需求真、被验证、我们缺货，就是机会 |
| E2 | 防假热闹：站外搜索热度在涨但站外销量不涨反跌的簇，热度还没变成购买，别提前进场 |
| E3 | 看规模别只看涨：搜索热度和竞对销量的绝对量级要和同轮其他候选比，明显小一档的簇撑不起稳稳破零，是擦线机会，要推价位带必须贴得住竞对价格带；客单价偏高的簇，即使需求在涨、价位带贴得住竞对价格带，我们平台的买家盘也撑不起稳稳破零——量级没有明显优势的别推 |
| E4 | 真缺口才值得推：站内一直有稳定订单的簇是存量生意，新发品抢的是老商家的单，流量再大、竞对卖得再多也别当缺口推；站内零订单、需求还在涨的簇才是真缺口 |
| E5 | 下单主力是目的性人群：运动健身、学生、白领这类带着明确需求来的人群，流量才有含金量；闲逛、捡漏人群几乎只看不买——判断破零潜力看目的性人群的流量，别被总流量唬住 |
| E6 | 多市场共振更可靠，但只是加分不是门槛：只有一国热、但那个市场热度够大、目的性人群对得上，照样能稳稳破零，别因为「只有一国热」就放弃 |
| E7 | 竞对价格带是接受度证据：竞对已经在卖的价位就是消费者验证过的价位；我们价位带明显高于竞对价格带的簇，需求再热也难破零，别推 |
| E8 | 验证过的机会优先复推，推过的簇及时止损：上轮破零的簇，主力市场大盘没塌（竞对销量还在涨或稳在高位、我们平台还是零供给）就继续推，复推优先；上轮没破零的簇再出现，先分清是簇本身需求不真，还是价位带没贴住竞对价格带——价位贴住后重推一轮还是没破零，就是簇在我们平台的买家盘撑不起，别再推；每轮把新过三层对照的簇也纳入候选，别只押老簇 |
