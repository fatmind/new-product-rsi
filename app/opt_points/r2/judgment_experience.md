# 研判经验（① 选品研判 prompt 的知识来源）

> 场景：3C 消费电子 - 大单品配件，出海电商。初版来自 spec/business_map.md §3。
> 自迭代规则：每轮可改 / 增 / 删条目，日志记编号；条目只写「怎么判断」，不写输出格式——格式约束写死在代码里，改经验不许动格式。

| 编号 | 经验 |
|---|---|
| E1 | 三层对照定新星：站外需求涨 + 站外销售涨 + 站内有需求没供给 = 需求真、被验证、我们缺货，就是机会 |
| E2 | 防假热闹：站外需求（搜索热度）在涨但站外销售不涨反跌的簇，热度还没变成购买，别提前进场 |
| E3 | 看规模别只看涨：搜索热度和竞对销量的绝对量级要和同轮其他候选比，明显小一档的簇撑不起稳稳破零，是擦线机会——这类簇要推，价位带必须贴得住竞对价格带，经不起价差 |
| E4 | 缺口看体量比例：站内有少量订单不等于供给充足，流量和竞对销量远大于站内订单量的还是大缺口；需求大而稳的大盘簇也值得推，破零确定性高 |
| E5 | 下单主力是目的性人群：分群流量里，运动健身、学生这类带着明确需求来的人群含金量高；只有闲逛、捡漏人群热度的簇要打折看 |
| E6 | 多市场共振更可靠：需求增长覆盖的市场越多越真，只有一国独热的降一档 |
| E7 | 竞对价格带是接受度证据：竞对已经在卖的价位就是消费者验证过的价位；我们价位带明显高于竞对价格带的簇，需求再热也难破零，别推 |
