# 研判经验（① 选品研判 prompt 的知识来源）

> 场景：3C 消费电子 - 大单品配件，出海电商。初版来自 spec/business_map.md §3。
> 自迭代规则：每轮可改 / 增 / 删条目，日志记编号；条目只写"怎么判断"，不写输出格式——格式约束写死在代码里，改经验不许动格式。

| 编号 | 经验 |
|---|---|
| E1 | 三层对照定新星：站外需求涨 + 站外销售涨 + 站内有流量没供给 = 需求真、被验证、我们缺货，就是机会 |
| E2 | 防假热闹：站内流量高但站外需求平，多半是刷出来的热闹；看流量是哪些人群贡献的——闲逛新客贡献的流量，含金量远不如带着目的搜的 |
| E3 | 价位带合理性：配件价位带一般是主机价格的 5%–15%；偏离太多的簇，需求可持续性存疑 |
| E4 | 主机保有量传导：配件需求跟着主机保有量走——主机销量在涨，配件需求滞后放大；主机熄火，配件跟着凉 |
| E5 | 竞对价格带是接受度证据：竞对已经在卖的价位，就是消费者验证过的价位，研判需求真实性时算正面证据 |
