## 1. 听供应链世界模型分享，再思考

原文：https://yuque.alibaba-inc.com/bohan.sj/wg84tn/uc0a41d2m2u8dmud

分享的核心：供应链已经把"数据 + 本体 + 业务地图 + API/CLI"搭成了一个 LLM 能理解、能推理、能操作的数字世界，解决了"自动执行"；下一步是把业务地图看成一张**计算图**，走向"结果优化"——

- 前向 = 给定一套策略，让整条链模拟跑到底，得到缺货和库存周转；
- Loss = 结果与目标的差距；
- 反向传播 = 沿业务链一层层往前拆：哪段策略影响最大、往哪调、调了会不会引发新问题；
- 供应链不可微，就用"固定初始状态、改一个变量、模拟对照"来估**策略梯度**；
- LLM 补足公式难表达的部分（模拟商家接量、角色行为），但结果数字由代码和专业模型算。

**我的再思考：这套机制值得先在一个更小的场s景验证——选品。** 为什么选品合适：

- 更好模拟：链路短，跑一圈就到头，供应链一条补货链有八九段；
- 对错有标准答案；

正好黑客松选品项目主流程已跑通，卡在"自迭代：怎么衡量判得对、怎么越判越准"想不清楚 —— 这套框架恰好就是答案。**共识：按世界模型思路把选品项目完全重构。**

## 2. 基础：本体、关系、动作、业务地图、环境

### 本体与关系：名词，世界里有什么、怎么关联

商品簇、需求、类目、价格带、国家、商家……以及它们之间的关系。场景无关——之间关系不会因为 "世界杯" 而改变，是世界里最稳定的一层。

关于"关系"，两条防错线：

- **关系是业务影响关系，不是传统 ER 的包含/引用关系**——要画的是"价格激励变了会影响商家发品意愿"这种影响传导，不是"商品属于类目"这种归属结构；
- **有业务主链路，才有关系，否则关系是硬造的**——本体建模最容易犯的错就是闭门画图，画一堆看着合理但没人用的关系。判据：关系必须被链路上某个动作用到，否则删掉。

本体不是数据表的别名，它有三重作用：

1. **约束经验录入**：业务经验必须写成对节点/关系的陈述，写不进本体的经验说明还没想清楚；
2. **指引经验取用**：研判命中哪个节点，自动带上挂在上面的经验；
3. **兜底无经验的推理**：LLM 遇到没经验可循的情况，不许自由发挥，沿本体关系推——先验耗尽时，世界结构兜底。

### 动作：动词，挂在本体的边上，分两类

有了关系，才会有动作。不同本体间的连接、本体自身的边，统称动作：

- **系统动作**：逻辑结构化，代码规则、传统优化算法——就是当前已经存在的各种系统（供应链系统、出价系统），对外提供 api/cli，是通用逻辑；
- **业务动作**：逻辑在人脑里，非结构化——原来只有人能跑。系统产出选品后小二还可以改、还可以导入别的，人脑才是终判。

另有一种**特殊动作：环境**——也挂在链上跑，但我们不可调节、只能从群体角度模拟（如消费者下单）。所以链上跑的全是动作，区别只是可调（系统/业务）不可调（环境）。

一个判别方法：**一条 2B 业务链路走完，中间一定有很多人参与——否则系统早就能全自动跑完了。**"链路里还有哪些人"就是"还有哪些判断没被结构化"的探测器。

LLM 在这个框架里的位置：系统动作不需要它；它的唯一价值是**第一次让业务动作能脱离人脑执行**。

### 世界怎么动起来：SOP 推进、动作执行、状态变化

2B 业务运行在"当前系统 + 人"的混合世界里，抽象建模后 = 本体、关系、业务链路 SOP、动作。随着 SOP 推进、动作执行，世界的状态/数据在发生变化——**状态不是独立一层，是动作执行留下的痕迹**：每执行一个动作 = 一次状态转移，都要落盘，反向传播查的就是这条轨迹。

### 业务地图：场景 → SOP，高于本体

- 本体是名词，地图是动词：看到当前状态，下一步做什么；
- "怎么办"一定是场景化的——暑假、大V直播、世界杯各有各的处理法，没法定义一个通用逻辑，所以地图从业务场景出发定义 SOP，思路高于本体；
- 这些逻辑为什么现在不在系统里？两个原因：
    - **系统实现追求通用，必然砍掉场景特异逻辑**，人工一直在干预/补齐；
    - **业务动作没进系统，本体上也没法提前刻画**，现状就散落在一个个场景里、在人脑里，即使有沉淀也非常粗；
- 所以**地图不是坐在屋里设计出来的，是从场景运行中挖出来的**。初版必然是粗的——是迭代起点，不是底稿；
- 主干永远能跑，业务永远转得下去；缺的是**特定场景的地图**，迭代要补的是场景分支。

### 环境：世界的物理定律，定死不动

- 消费者怎么买、商家怎么想 = 环境，它是一种**特殊动作**：实验运行不可或缺，但**不是优化对象**——真实世界里你也改变不了消费者；
- **实验运行中**环境保持不动
- 类比：环境 = 数据分布，不优化；策略 = 网络参数，被优化。
